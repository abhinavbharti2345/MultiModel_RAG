# Project Rules

## Caveman Mode (ALWAYS ON)

Before responding to ANY user message, read and follow `.agents/skills/caveman/SKILL.md`.

- Active by default on every response, first message onward. Do not wait for "caveman mode" or `/caveman` to be invoked.
- Follow its Persistence section: no revert across turns, no filler drift.
- Default intensity: **full**. User can switch via `/caveman lite|full|ultra|off`.
- Auto-Clarity and Boundaries sections still apply (warnings, irreversible actions, code/commits/docs stay normal prose).
